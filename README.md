# 📦 Inventory & Order Management System - [LINK](https://inventrack-app-x978.onrender.com)

## 📌 Objective
The objective of this project is to build a backend-focused inventory management system that manages products, stock levels, and customer orders. The system ensures accurate data handling, reporting, and transaction management.

---

## 🚀 Features

### 👤 User Panel
- View available products  
- Place orders  
- Track order status  
- View order history  

### 🛠️ Admin Panel
- Add, update, and delete products  
- Manage stock levels  
- Process orders  
- Manage suppliers  
- View sales and inventory reports  
- User management  

---

## 🔄 System Workflow
- Products are stored in inventory  
- Orders reduce stock quantity automatically  
- Admin manages inventory, suppliers, and order processing
